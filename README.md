# TKCB-Nm Flash AS3 小练习
这里是我自己（TKCB-Nm）独家分享的，个人在学习Flash AS3过程中的小练习（针对每个知识点进行独立的练习，且注释齐全，网友反馈都说非常好）。

小练习有几百个，已经做了基本的文件夹分类，具体需要的时候还可以进行关键字搜索，因为每个小练习的文件名都包含了尽可能相关的关键字和词汇。

相信对 11RIA 闪客社区 有记忆的同学，都对TKCB小练习有一些印象，所以我再次整理后，分享给大家，这次更全，更好，更方便。
