删除 /* */ 注释：    		/\*{1,2}[\s\S]*?\*/
  
删除 // 注释：    		//[\s\S]*?\n

删除 XML || HTML 注释：  	<!-[\s\S]*?-->

删除 空白行：  			^\s*\n

删除 空白行+缩进(含空格)：  	(^\s*\n)|(\t)|(^\s+)

删除 // 和 /* */ 注释：		/\*([^*]|[\r\n]|(\*+([^*/]|[\r\n])))*\*+/|[\t]*//.*


第一步：【手动】用上面的各种 正则 + Notepad++软件 剔除注释、空行、缩进


第二步：JS加密/压缩（勾选 eval加密 + 缩短变量名）
https://www.sojson.com/js.html


第三步：JS代码混淆
https://www.sojson.com/jscodeconfusion.html


特殊：也可以手动之后，选择【最牛加密】【不要勾选禁用控制台调试】，适合main.js，类库js建议本地加密
https://www.sojson.com/jsobfuscator.html


提示：先手动剔除，再自动加密+混淆，这样JS基本安全了。
